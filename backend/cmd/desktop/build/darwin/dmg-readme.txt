macOS Installation / macOS 安装说明
=====================================

Drag Hephaestus.app to Applications folder to install.
将 Hephaestus.app 拖到 Applications 文件夹即可安装。

If macOS shows "Hephaestus is damaged and can't be opened":
如果 macOS 提示 "Hephaestus 已损坏，无法打开"：

Open Terminal and run / 打开终端执行：

    sudo xattr -cr /Applications/Hephaestus.app

Then open Hephaestus.app again.
然后重新打开 Hephaestus.app 即可。
