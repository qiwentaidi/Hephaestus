# 授权测试与风险条款

Hephaestus 的扫描、漏洞验证、AI 工具调用和 Agent 执行均应在合法授权范围内开展。涉及客户资产或第三方系统时，测试方必须在发起任何探测前取得有权授权方的明确书面授权。若客户无权授权某项第三方资产，应先取得该资产权利人或其授权代表的书面同意。

## 测试前

- 书面约定允许测试的域名、IP、网段、应用和账号，明确排除目标、测试窗口、允许的手段、并发或速率上限，以及双方的应急联系人和停测条件。
- 对生产系统中的高风险操作单独取得明确授权，例如口令尝试、可能影响可用性的压力测试、写入数据或可能改变系统状态的漏洞验证。
- 确认测试数据的访问范围、保存期限和交付方式。使用外部 AI 模型、资产搜索服务或远程 Agent 前，确认授权允许将目标信息和测试数据发送到相应服务或节点。

## 测试中

- 将手动任务、组合任务、AI 工具和各 Agent 都限制在约定范围内。发现的新资产、重定向目标、共享基础设施和关联账号须确认在授权范围内后才能继续测试。
- 主动探测可能引起告警、账号锁定、业务中断、数据变更或敏感信息泄露。按约定控制流量和并发，优先采用影响较低的验证方式。
- 发现越界、异常影响，或授权到期、被撤回时，立即停止相关任务，确认 Agent 停止执行，按约定通知客户并记录事件。

## 测试后

- 仅保留验证和报告所需的证据，限制访问并对凭据、个人信息和敏感业务数据作脱敏处理。按约定提交报告并归还或删除数据与临时测试产物。
- 测试方负责核验授权、遵守适用法律和客户约定，并处理测试行为产生的影响。软件以 Apache License 2.0 及适用的第三方许可提供，软件许可与目标资产的测试授权分别适用。见 [LICENSE](../LICENSE)。
